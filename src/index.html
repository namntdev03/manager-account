Quy tắc theo thư mục

Gán một thư mục cho một tài khoản. Mọi repo nằm trong thư mục đó tự dùng đúng tài khoản, không cần bấm “Dùng tài khoản này”.

Sao lưu ra file

Gom toàn bộ tài khoản, SSH host và quy tắc theo thư mục vào một file đã mã hoá bằng mật khẩu của bạn.

  • Tài khoản Git, npm, SSH cùng token, mật khẩu và private key (đã mã hoá trong file).
  • Danh sách SSH host và các quy tắc theo thư mục.
  • Không gồm: cài đặt giao diện, file đã tải lên hay tải về.

Mất mật khẩu này thì không thể mở lại file, app không giữ bản nào. Hãy cất file ở nơi an toàn.

Khôi phục từ file

Dùng khi chuyển sang máy mới hoặc cài lại máy. Dữ liệu trong file được thêm vào app, tài khoản trùng mã sẽ bị ghi đè.

Dữ liệu của bạn ở lại trên máy
  • Khi kiểm tra cập nhật, app chỉ gửi một yêu cầu đọc (GET) tới api.github.com/repos/namntdev03/manager-account/releases/latest.
  • Khi bạn bấm Cập nhật ngay, app tải file cập nhật từ GitHub Releases của dự án và kiểm tra chữ ký số trước khi cài. Không có dữ liệu nào của bạn được gửi đi.
  • App không gửi tên, email, token, SSH key, danh sách tài khoản, đường dẫn repo hay bất kỳ dữ liệu nào của bạn.
  • GitHub chỉ thấy địa chỉ IP và yêu cầu như mọi lượt truy cập web thông thường. Bạn có thể tắt tự kiểm tra ở trên.
  • Tài khoản, token và cấu hình chỉ nằm trên máy này (token trong kho bảo mật của hệ điều hành).

Manager Account

Phiên bản —

Quản lý tài khoản Git, npm và SSH, kết nối server và sao lưu mọi thứ ngay trên máy bạn. Chạy trên macOS, Windows và Linux.

App này làm gì?

Nếu bạn làm việc với nhiều tài khoản (GitHub, GitLab, Bitbucket, npm registry, các server SSH), mỗi lần đổi qua lại thường phải sửa cấu hình và đăng nhập lại thủ công. App gom tất cả vào một chỗ.

  • Tài khoản Git. Lưu nhiều tài khoản (user.name, user.email, SSH key hoặc Personal Access Token) và đổi bằng một cú bấm, cho toàn máy hoặc chỉ một repo. Quy tắc theo thư mục tự dùng đúng tài khoản cho mọi repo trong một thư mục. Có thể tạo SSH key ed25519 ngay trong app.
  • Tài khoản npm. Lưu token cho npmjs, GitHub Packages hoặc registry riêng (theo scope), rồi ghi vào .npmrc khi bạn bấm dùng.
  • SSH host. Kết nối server bằng terminal ngay trong app (nhiều tab), mật khẩu và passphrase của key được tự điền. Có thể duyệt, tải lên, tải về, đổi tên và xoá file trên server qua SSH.
  • Kho lưu trữ. Sao lưu toàn bộ tài khoản, SSH host và quy tắc vào một file mã hoá bằng mật khẩu của bạn, rồi khôi phục khi đổi sang máy khác.
  • Kubernetes, ArgoCD, Harbor, Docker. Lưu kubeconfig (mã hoá), token ArgoCD, tài khoản Harbor và Docker registry, đổi cluster hoặc đăng nhập bằng một cú bấm, có nhãn production để tránh nhầm.
  • Hiệu năng. Xem RAM, CPU và số phiên SSH mà chính app đang dùng.

App thay đổi gì trên máy của bạn?

App chỉ làm những việc dưới đây, bạn có thể tự kiểm tra bất cứ lúc nào:

  • git config bình thường: user.name, user.email, core.sshCommand (trỏ tới đúng SSH key), credential.https://<host>.username cùng việc nạp token vào git credential của hệ điều hành, và remote.<tên>.url chỉ khi bạn tick “Đổi remote SSH ⇄ HTTPS”.
  • Quy tắc theo thư mục: thêm các dòng includeIf "gitdir:…" vào ~/.gitconfig, mỗi dòng trỏ tới một file cấu hình nhỏ trong thư mục dữ liệu của app. Xoá quy tắc thì các dòng này bị gỡ.
  • npm: ghi token và registry= vào ~/.npmrc hoặc .npmrc của repo, các dòng khác giữ nguyên.
  • SSH và quản lý file: app chạy lệnh ssh có sẵn của hệ điều hành. Mật khẩu và passphrase được điền qua cơ chế SSH_ASKPASS (chính app đọc Keychain, không ghi ra file). Phần quản lý file chạy các lệnh ls, cat, tar, mkdir, mv, rm trên server bạn chọn qua kết nối SSH đó.
  • Kubernetes, ArgoCD, Docker, Harbor: ghi ~/.kube/config và ~/.config/argocd/config (file cũ của bạn được sao lưu trước), hoặc chạy docker login tới Harbor / Docker registry khi bạn bấm dùng tài khoản.

Chính sách dữ liệu & quyền riêng tư

  • Dữ liệu chỉ nằm trên máy bạn. Không có server của app, không tài khoản người dùng, không thống kê, không quảng cáo, không bán hay chia sẻ dữ liệu cho bên thứ ba.
  • Nơi lưu: thông tin tài khoản, SSH host và quy tắc (tên, email, host, đường dẫn key…) nằm trong thư mục dữ liệu của app; token, mật khẩu SSH và passphrase nằm trong kho bảo mật của hệ điều hành (Keychain / Credential Manager / Secret Service), không ghi vào file thường; private key dán hoặc tạo trong app được lưu thành file riêng quyền 600; kubeconfig được mã hoá thành file riêng, khoá giải mã nằm trong kho bảo mật.
  • Khi nào app dùng mạng: (1) kiểm tra bản cập nhật, chỉ một yêu cầu đọc tới GitHub Releases của dự án, tắt được ở Cài đặt; (2) khi bạn bấm Cập nhật ngay, tải file cập nhật từ GitHub Releases của dự án; (3) khi bạn bấm Test kết nối, chỉ tới đúng nền tảng hoặc máy chủ của tài khoản đó (GitHub, GitLab, npm registry, Kubernetes, ArgoCD, Harbor, Docker registry); (4) khi bạn mở terminal hoặc quản lý file của một SSH host, kết nối SSH tới chính máy chủ đó; (5) khi bạn bấm Mở trang thêm key, app chỉ mở trình duyệt tới trang SSH key của GitHub/GitLab, không gửi gì kèm theo.
  • Không bao giờ gửi tên, email, token, mật khẩu, SSH key, danh sách tài khoản, danh sách SSH host hay đường dẫn repo của bạn tới bất kỳ đâu.
  • Kho lưu trữ: file sao lưu chứa mọi bí mật của bạn, được mã hoá bằng mật khẩu bạn đặt (Argon2id và ChaCha20-Poly1305). App không giữ mật khẩu đó và không tự tải file lên đâu cả. Mất mật khẩu thì không thể mở lại file. Hãy cất file ở nơi an toàn.
  • Xác thực khi xem bí mật: hiện token, mật khẩu, key, passphrase hoặc tạo file sao lưu sẽ hỏi Touch ID / mật khẩu máy (macOS), Windows Hello hoặc PIN (Windows), mật khẩu hệ thống (Linux). Tính năng bật mặc định và tắt được ở Cài đặt. Nó chặn người khác dùng ké lúc app đang mở, nhưng không ngăn được phần mềm khác chạy dưới tài khoản của bạn đọc trực tiếp kho bảo mật của hệ điều hành.
  • Cập nhật: app báo khi có bản mới; chỉ khi bạn bấm Cập nhật ngay app mới tải về. File cập nhật được kiểm tra chữ ký số (minisign) trước khi cài, file giả hoặc bị sửa sẽ bị từ chối.
  • Xoá dữ liệu: xoá tài khoản trong app sẽ xoá token, mật khẩu, passphrase và key tương ứng. Muốn gỡ sạch, xoá thư mục dữ liệu của app (macOS: ~/Library/Application Support/com.nguyenthanhnam.manageraccount; Windows: %APPDATA%\com.nguyenthanhnam.manageraccount; Linux: ~/.local/share/com.nguyenthanhnam.manageraccount) và mục manager-account trong Keychain / Credential Manager, rồi xoá các dòng includeIf do app thêm trong ~/.gitconfig nếu bạn đã dùng quy tắc theo thư mục.

Bạn tự nhập một lần, sau đó chỉ cần bấm chọn để đổi.

      

      


      

        
        
        
      


      

        
        
        
        
        
Bạn có thể dùng mật khẩu, key (RSA, ED25519, ECDSA… mọi loại key OpenSSH) hoặc cả hai. Mật khẩu lưu trong kho bảo mật của hệ điều hành và được tự điền khi kết nối. Không có cả hai thì terminal sẽ hỏi.

      


      

      

      

        
        
Dùng một account token riêng cho app, quyền vừa đủ (ví dụ chỉ đọc), tạo bằng argocd account generate-token --account <tên>. Nếu ArgoCD không mở ra ngoài, dùng https://localhost:8080 sau khi kubectl port-forward, rồi bật tuỳ chọn chứng chỉ tự ký. Khi bấm “Dùng tài khoản này”, app ghi ~/.config/argocd/config (mỗi tài khoản là một context) và sao lưu file cũ nếu có.

        
Dùng tên đăng nhập và một access token thay vì mật khẩu (Docker Hub, GitHub Container Registry hoặc registry riêng). Để địa chỉ https://docker.io cho Docker Hub. Khi bấm “Dùng tài khoản này”, app chạy docker login (cần cài Docker), thông tin đăng nhập do Docker lưu theo cấu hình của bạn (thường là Keychain / Credential Manager).

        
Nên dùng robot account thay vì tài khoản cá nhân. Khi bấm “Dùng tài khoản này”, app chạy docker login tới Harbor này (cần cài Docker), thông tin đăng nhập do Docker lưu theo cấu hình của bạn.

      


      

        
        
        
Dán nội dung kubeconfig đã nhúng sẵn chứng chỉ (lấy bằng kubectl config view --flatten --minify --raw). App mã hoá nội dung này thành file riêng, khoá nằm trong kho bảo mật của hệ điều hành. Khi bấm “Dùng tài khoản này”, app ghi vào ~/.kube/config và sao lưu file cũ của bạn nếu có. Cluster đánh dấu production sẽ hỏi xác nhận trước khi đổi.

      


      

        
        
Để trống nếu muốn dùng registry này cho mọi package. Khi bấm “Dùng tài khoản này”, app ghi token vào file .npmrc (toàn máy hoặc trong repo) đúng như npm yêu cầu, nên file này chứa token dạng chữ thường. Không commit .npmrc có token lên git.
