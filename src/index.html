Quy tắc theo thư mục

Gán một thư mục cho một tài khoản. Mọi repo nằm trong thư mục đó tự dùng đúng tài khoản, không cần bấm “Dùng tài khoản này”.

Sao lưu ra file

Gom toàn bộ tài khoản, SSH host và quy tắc theo thư mục vào một file đã mã hoá bằng mật khẩu của bạn.

  • Tài khoản Git, npm, SSH cùng token, mật khẩu và private key (đã mã hoá trong file).
  • Danh sách SSH host và các quy tắc theo thư mục.
  • Không gồm: cài đặt giao diện, file đã tải lên hay tải về.

Mất mật khẩu này thì không thể mở lại file, app không giữ bản nào. Hãy cất file ở nơi an toàn.

Khôi phục từ file

Dùng khi chuyển sang máy mới hoặc cài lại máy. Dữ liệu trong file được thêm vào app, tài khoản trùng mã sẽ bị ghi đè.

Dữ liệu của bạn ở lại trên máy
  • Khi kiểm tra cập nhật, app chỉ gửi một yêu cầu đọc (GET) tới api.github.com/repos/namntdev03/manager-account/releases/latest.
  • Khi bạn bấm Cập nhật ngay, app tải file cập nhật từ GitHub Releases của dự án và kiểm tra chữ ký số trước khi cài. Không có dữ liệu nào của bạn được gửi đi.
  • App không gửi tên, email, token, SSH key, danh sách tài khoản, đường dẫn repo hay bất kỳ dữ liệu nào của bạn.
  • GitHub chỉ thấy địa chỉ IP và yêu cầu như mọi lượt truy cập web thông thường. Bạn có thể tắt tự kiểm tra ở trên.
  • Tài khoản, token và cấu hình chỉ nằm trên máy này (token trong kho bảo mật của hệ điều hành).

Phiên bản —

Đổi nhanh giữa nhiều tài khoản Git chỉ với một cú bấm. Chạy trên macOS, Windows và Linux.

App này làm gì?

Nếu bạn dùng nhiều tài khoản GitHub, GitLab hay Bitbucket (cá nhân, công ty…), mỗi lần đổi qua lại thường phải sửa tên, email và đăng nhập lại thủ công. App gom tất cả vào một chỗ.

  • Lưu nhiều tài khoản. Mỗi tài khoản gồm user.name, user.email và cách đăng nhập: SSH key hoặc Personal Access Token.
  • Đổi tài khoản một cú bấm, áp dụng cho toàn máy hoặc chỉ cho một repo. Tuỳ chọn tự đổi remote giữa SSH và HTTPS cho khớp.
  • Biết tài khoản nào đang hoạt động trên từng nền tảng, lọc theo GitHub / GitLab / Bitbucket hoặc host khác.
  • Test kết nối để chắc key hoặc token đang đăng nhập đúng tài khoản.

App thay đổi gì trong git của bạn?

App chỉ chạy lệnh git config bình thường và ghi các khoá sau, bạn có thể tự kiểm tra bất cứ lúc nào:

  • user.name, user.email: danh tính trên commit.
  • core.sshCommand: trỏ tới đúng SSH key (tài khoản dùng SSH).
  • credential.https://<host>.username và nạp token vào git credential của hệ điều hành (tài khoản dùng token).
  • remote.<tên>.url: chỉ khi bạn tick “Đổi remote SSH ⇄ HTTPS”.

Chính sách dữ liệu & quyền riêng tư

  • Dữ liệu chỉ nằm trên máy bạn. Không có server của app, không tài khoản người dùng, không thống kê, không quảng cáo, không bán hay chia sẻ dữ liệu cho bên thứ ba.
  • Nơi lưu: thông tin tài khoản (tên, email, host, đường dẫn key) trong thư mục dữ liệu của app; token trong kho bảo mật của hệ điều hành (Keychain / Credential Manager / Secret Service), không ghi vào file thường; private key dán vào app lưu thành file riêng quyền 600.
  • Khi nào app dùng mạng: (1) kiểm tra bản cập nhật, chỉ một yêu cầu đọc tới GitHub Releases của dự án, tắt được ở Cài đặt; (2) khi bạn bấm Cập nhật ngay, tải file cập nhật từ GitHub Releases của dự án; (3) khi bạn bấm Test kết nối, chỉ tới đúng nền tảng của tài khoản đó.
  • Không bao giờ gửi tên, email, token, SSH key, danh sách tài khoản hay đường dẫn repo của bạn tới bất kỳ đâu.
  • Cập nhật: app báo khi có bản mới; chỉ khi bạn bấm Cập nhật ngay app mới tải về. File cập nhật được kiểm tra chữ ký số (minisign) trước khi cài, file giả hoặc bị sửa sẽ bị từ chối.
  • Xoá dữ liệu: xoá tài khoản trong app sẽ xoá token và key tương ứng. Muốn gỡ sạch, xoá thư mục dữ liệu của app (macOS: ~/Library/Application Support/com.nguyenthanhnam.manageraccount; Windows: %APPDATA%\com.nguyenthanhnam.manageraccount; Linux: ~/.local/share/com.nguyenthanhnam.manageraccount) và mục manager-account trong Keychain / Credential Manager.
