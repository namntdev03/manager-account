Manager Account

          

          
        

        

        

        
        

          Dữ liệu của bạn ở lại trên máy
          
    
            
  • Khi kiểm tra cập nhật, app chỉ gửi một yêu cầu đọc (GET) tới api.github.com/repos/namntdev03/manager-account/releases/latest.
    • 
            
  • App không gửi tên, email, token, SSH key, danh sách tài khoản, đường dẫn repo hay bất kỳ dữ liệu nào của bạn.
    • 
            
  • GitHub chỉ thấy địa chỉ IP và yêu cầu như mọi lượt truy cập web thông thường. Bạn có thể tắt tự kiểm tra ở trên.
    • 
            
  • Tài khoản, token và cấu hình chỉ nằm trên máy này (token trong kho bảo mật của hệ điều hành).

        Cách đăng nhập
        

          
          
        


        

          
          
          
Nếu dán key, app lưu thành file riêng (quyền 600) trong thư mục dữ liệu của app. Key có passphrase cần nạp vào ssh-agent trước.

        


        

          
          
          
Token được lưu trong kho bảo mật của hệ điều hành (Keychain / Credential Manager / Secret Service), không ghi vào file thường.
